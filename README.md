## 🚀 Избранные проекты

### 🏋️ Система компьютерного зрения для анализа техники тренировок (ВКР)
Распознавание фаз упражнений и биомеханических ошибок в реальном времени по видео с веб-камеры.
`Python` `MediaPipe` `OpenCV` `XGBoost` `scikit-learn`

- Pose estimation через MediaPipe (33 ключевые точки), нормализация координат
- Классификатор фаз упражнений на XGBoost + эталонно-ориентированный анализ ошибок техники
- Модульная архитектура, конечный автомат сессии, автогенерация отчёта
